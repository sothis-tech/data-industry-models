# Referencias a modelos oficiales

Este proyecto reutiliza y extiende los siguientes Smart Data Models. Las extensiones se documentan en [docs/extensions.md](docs/extensions.md).

## Modelos utilizados

| Modelo | Repositorio | Entidades |
|--------|-------------|-----------|
| ManufacturingMachine | [dataModel.ManufacturingMachine](https://github.com/smart-data-models/dataModel.ManufacturingMachine) | ManufacturingMachine, ManufacturingMachineModel, ManufacturingMachineOperation |
| Device | [dataModel.Device](https://github.com/smart-data-models/dataModel.Device) | Device, DeviceMeasurement |
| Building | [dataModel.Building](https://github.com/smart-data-models/dataModel.Building) | Building |
| Person | Schema.org | Person |
